# Per-URL intelligence report — illustrative sample

Open `sample-report.html` or choose **Sample report** in Latch to preview the layout. All sample evidence is fictional; no real screenshot or AI request is represented.

Reports include the analyst rationale, domain intelligence, optional AI synthesis, the actual Firefox visit screenshot, static code indicators, reputation sources, and evidence gaps. Use `npm run smoke` inside the isolated VM to create an actual `example.com` visit report and screenshot.
